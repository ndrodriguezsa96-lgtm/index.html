La modalidad de Programación y Diseño Web se enfoca en la creación de páginas y aplicaciones para internet, combinando la parte visual con la lógica de funcionamiento. En esta área se aprenden herramientas como HTML, CSS y JavaScript, además de pr incipios de diseño, organización de contenidos , experiencia de usuario y desarrollo de interfaces atractivas y funcionales. También permite crear sitios web responsivos, es decir, que se adapten a celulares, tabletas y computadores, preparando al estudiante para diseñar y construir soluciones digitales modernas y útiles.
